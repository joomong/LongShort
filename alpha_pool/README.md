# alpha_pool

승인된 알파를 두는 공용 폴더다. 알파 하나가 폴더 하나이고, 폴더에는 두 파일이 반드시 있다.

```text
alpha_pool/<alpha_name>/
  alpha.xml    # 엔진에서 그대로 돌아가는 정의
  README.md    # 설명 (필수)
```

README.md에는 적어도 다음을 적는다: 무엇을 거래하나(방향 포함), XML 단계별 설명, 데이터·지연·유니버스·체결·비용, 전체 기간 비용 후 Sharpe와 연도별 수치(측정일·엔진 명시), 풀 안 다른 알파와의 상관, 주의, 작성자와 원 연구 경로.

승인된 알파는 고치지 않는다. 바꾸려면 새 이름으로 넣고 이전 폴더의 README 첫 줄에 대체된 알파를 적는다. 모듈은 여기 두지 않는다. 알파가 새 모듈을 쓰면 모듈을 플랫폼 기본 모듈(`cpp-engine/src/modules/`)로 먼저 올린다.

엔진은 config `alpha_pool`로 이 폴더의 `alpha.xml`만 읽어(쓰지 않음) 화면 결과표의 `Corr` 열, 즉 풀 동일가중 손익과의 상관을 만든다.

처음 들어온 11개는 combo15의 구성 알파다(2026-10-29, jgo).
