## 무엇을 거래하나

섹터 안 공통 요인(PCA)으로 설명되지 않는 가격 수준의 괴리가 되돌아오는 것(평균회귀)을 거래한다. 종목별 분수 차분(FFD) 가격을 섹터별 PCA로 재구성하고, `재구성 − 실제`를 신호로 쓴다. 실제가 재구성보다 높으면 음수(숏), 낮으면 양수(롱)다. 신호는 순위로 바꾸고 섹터 중립화한다.

## XML

```xml
<data expr="close/adj_factor" delay="1" />
<ffd d="0.24" thres="0.00001" />
<pcaresid group="sector" train="1260" refit="252" var="0.9" />
<rank />
<neutralize group="sector" />
```

| 단계 | 하는 일 |
|---|---|
| `<data expr="close/adj_factor" delay="1"/>` | 전일 분할조정 종가 |
| `<ffd d="0.24" thres="0.00001"/>` | 분수 차분. 가중치 w₀=1, w_k = −w_{k−1}/k·(d−k+1), \|w_k\|<thres 또는 1000개에서 멈춤(이 설정은 1000개). 입력을 첫 유효값부터 forward-fill한 뒤 가중합. 첫 유효값 뒤 1000영업일(약 4년)은 NaN |
| `<pcaresid group="sector" train="1260" refit="252" var="0.9"/>` | 섹터별 롤링 PCA 잔차. 패널 bar b(b≥1260, b%252==0)마다 직전 1260일(5년)로 학습, 다음 252일(1년)은 고정. 학습 집합: 학습 구간 내내 유니버스 멤버·같은 섹터·FFD 유효한 종목. 종목별 학습 평균·표준편차로 표준화(ddof 0, 표준편차 0은 제외), sklearn PCA(누적 설명분산 ≥ 0.9). 출력 z_hat − z, z_hat = mu + V·s, s는 관측된 좌표의 최소제곱 점수 |
| `<rank/>` | 횡단면 순위 |
| `<neutralize group="sector"/>` | 섹터 평균 제거 |

표준화 z = (x − μ)/σ는 종목별 상수 배율에 불변이므로 `close/adj_factor`의 단위 선택 자체는 신호를 바꾸지 않는다. 분할을 look-ahead 없이 다루는 논의와 운영 정의와의 차이(cohort, offset −μ)는 원문 notes §1.2·§2.2에 있다.
