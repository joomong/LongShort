## 후속(Phase 2f, 같은 날)

리뷰 뒤 추가 지적 3건(앵커 필수·347행의 실제 영향·카운터 분류)과 사용자 결정(데이터 없으면 찾아서 채움)에 대한 처리는 완료 문서 §13에 있다. 요지: 로더가 평가 입력이 있으면 앵커를 강제하고, 가드 카운터는 검사 완료/기간 밖/평가 불가로 분할해 합이 매칭 행 수와 같음을 도구가 검사하며(부분 기간 fixture 포함), opt-in 정산 로그로 기본 R 정산의 실제 노출·손익 영향을 사유별로 측정했다(Top500 28.6% → 백필 후 12.7%). 백필은 근거 필수 override(35행, SEC 8-K/DEFM14A)와 생성기 승계사 리졸버(gvkey 매치 보존)로 진행했고, 1차 리졸버가 만든 회귀 38종목은 종목 단위 추적으로 잡아 전부 복구했다. 선택형 대가(EITHER/ELECT)는 기입하지 않고 정책 결정 대기.

## Phase 2g — 백필 정확성 감사 (팀 제안 채택)

"기능 추가를 멈추고 백필 35행의 정확성을 먼저 확인"하자는 제안을 그대로 따랐다. 기입 담당과 분리된 독립 검토가 5항목 체크리스트(종목 id·대가의 주어·가격 단위/연속성·적용일·1차 근거)로 행별 판정했고 결과는 완료 문서 §14에 있다. 요지: 35행 중 confirmed 17·corrected 17·unresolved 1. TYC는 지적대로 JCI 주주의 프로레이션 조건을 Tyco 주주에 적용한 오류였고(0.955 병합·현금 0), 캐시 TYC 라인이 이미 신주 단위라 캐시 단위 교환비는 1.0이 맞음(누적 −1.09%로 DB 실보유자와 일치). 종료일 12건 정정은 개별 오류가 아니라 규칙 문제라 `endDate = min(endDate, 마지막 캐시 종가일)`을 전 행에 적용했고(1,572행), k_t 측정일도 종료일 이하 마지막 종가일로 일반화했다. 선택형은 제안대로 "미선택 주주의 최종 배정"만 기입(14건, 2차 독립 검토 통과·조건 오류 0)하고 확인 안 되는 3건은 미평가로 남겼다. 전후 비교는 정산 로그로 종목별 대조했으며 허용 목록 밖 구조 변경 0건, 정산일 손익 차이 합과 유형별 분해·default 노출 비율 변화를 §14에 기록했다. 남은 데이터 한계(캐시에 없는 승계 라인, 스핀오프 미조정 갭, SPAC·역합병 조건 부재)는 기본 R 사용 사실과 손익 영향으로 드러내는 것까지를 이번 범위로 했다.

### Phase 2g 후속 리뷰(같은 날 밤) — 완료 판정 철회

위 문단의 "허용 목록 밖 구조 변경 0건"과 "1,572행 캡"은 후속 리뷰 3건을 반영하기 전의 서술이라 완료 판정을 철회한다. ① 비교 게이트가 승계사 id·주식 이전량·현금/주식 배분 변경을 거절하지 않았음(허용 목록 없이도 PASS) → 구조 필드 확장과 반례 3종 self-test로 보완. ② 종료일 일괄 캡은 과도함 → 감사로 확인된 정정만 유지하고, 캡은 효력일이 뒷받침하거나 5일 이내인 경우만 적용, 그 밖은 원 종료일 + 검토 표시. ③ −0.053은 3유니버스×5알파×2가정의 정산 손익 차이 합산이지 전략 손익 변화가 아님 → 셀별 표와 보유손익 포함 전체 PnL 변화로 다시 제시. 세 건 반영·재실행 후 판정을 다시 쓴다(완료 문서 §14).

반영 결과(완료 문서 §14 끝): ① 게이트에 승계사·현금/주식 배분·이전 비율을 구조 필드로 넣어 반례 3종이 FAIL, 실제 승계사 변경 6종목 180행 포착. ② 종료일 캡을 기록일 근접 추정 1,292 / 갭 추정 96 / flagged 184(원 종료일 유지)로 분리, override 48행은 캡 제외; flagged 원복의 정산일 손익 차이 합산 −0.0019(−19bp, 실행 합), estimate 기여 0. ③ 정산일 차이는 유니버스×알파×R 표로, 전체 PnL은 run 단위(최대 Top500/afl_100 R=−1 −0.0264, Sharpe −0.015). 세 유니버스 30회 재실행·게이트 PASS. 프로세스 확인은 `ps` 명령 결과(엔진·하네스·생성기 0개)를 증거 폴더에 남김.
